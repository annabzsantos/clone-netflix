# 🎬 Netflix Clone

Um clone da interface da **Netflix** desenvolvido para praticar conceitos de desenvolvimento web frontend, manipulação do DOM e estilização responsiva.

> 🚀 **Deploy:** O projeto está publicado e pode ser acessado através do [GitHub Pages](https://annabzsantos.github.io/clone-netflix/).

---

## 📌 Sobre o Projeto

Este projeto recria a interface de usuário da plataforma de streaming Netflix, apresentando um catálogo de filmes/séries, gerenciamento de temas (modo claro/escuro) e navegação responsiva.

---

## 📁 Estrutura do Repositório

| Arquivo / Pasta | Descrição |
| :--- | :--- |
| 📂 **`assets/`** | Recursos visuais do projeto (imagens, ícones, logos, banners). |
| 📂 **`catalogo/`** | Módulos e dados/componentes do catálogo de filmes e séries. |
| 📂 **`js/`** | Scripts JavaScript contendo as funcionalidades dinâmicas da aplicação. |
| 📄 **`index.html`** | Estrutura principal da página web. |
| 📄 **`styles.css`** | Estilização CSS do projeto (layout, temas, responsividade, animações). |
| 📄 **`theme.js`** | Lógica de alternância de temas (Dark/Light mode). |

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização responsiva, layout flexível, transições e variáveis de tema.
- **JavaScript (ES6+):** Manipulação de elementos do DOM, interatividade e troca de tema.
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.

---

## ✨ Funcionalidades

- 📱 **Interface Responsiva:** Adaptada para diferentes tamanhos de tela.
- 🎨 **Alternância de Tema (Theme Switcher):** Suporte a modo claro e escuro gerenciado via `theme.js`.
- 🍿 **Catálogo de Mídias:** Exibição organizada de conteúdos e filmes.
